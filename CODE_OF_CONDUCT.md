# Código de Conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Resumo: seja respeitoso e acolhedor; não toleramos assédio, discriminação, ataques pessoais ou divulgação de dados privados de terceiros. Mantenedores podem remover contribuições e banir quem violar estas regras, dentro e fora do projeto quando representá-lo.

Denúncias: abra uma issue privada de segurança/aviso aos mantenedores pelo GitHub (ou contate o mantenedor do repositório). Todas serão analisadas com confidencialidade.
