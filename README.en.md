# apuracao-rj

Desktop dashboard (Tauri v2) to follow the **2026 presidential runoff results in Rio de Janeiro state** (state total plus 92 municipalities).

> **Unofficial project.** Not affiliated with Brazil's electoral court (TSE). Data comes from TSE public results and may lag or differ; always check the TSE for official results.

- Data: TSE public results; municipal boundaries from IBGE (see [NOTICE.md](NOTICE.md)).
- Dev: `npm ci && npm run dev` (browser, mock data); `npm run tauri dev` (desktop); `cargo test -p apuracao-core`.
